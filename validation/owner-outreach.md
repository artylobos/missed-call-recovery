# Owner Outreach Kit

## First Message

Subject: missed emergency plumbing calls

```text
Hi {owner_name}, I am testing missed-call recovery for emergency plumbing jobs
in {city}.

It texts missed callers within 60 seconds, collects what they need, and sends
you a clean lead summary. No full AI receptionist needed for the first pilot.

If you missed even 3-5 calls last week, I can show you a 5 minute demo using
your business name. Would it be useful to see whether this could recover one
extra job this week?
```

## Call Opener

```text
I am not trying to replace your front desk. I am trying to recover the calls
you already miss when staff are busy or after hours. How many missed calls did
you have last week?
```

## Paid Pilot Close

```text
If we can start with missed-call textback only, I can set up a 7 day pilot.
You will get a daily report showing missed calls, replies, qualified leads, and
appointments or quote requests. The pilot is {price}. If it does not recover
useful leads, we stop.
```

## Safety Boundary

```text
We do not diagnose, quote, promise dispatch, or answer as the plumber. The first
pilot only texts back, collects name/phone/suburb/problem/urgency, and alerts
you immediately.
```

## Objection: We Already Have Voicemail

```text
That is exactly the gap. Voicemail waits for the customer to leave a message.
This responds while intent is still fresh and gives you a structured lead.
```

## Objection: I Do Not Want AI Talking To Customers

```text
Then we should not start with AI voice. We can start with missed-call textback:
short SMS, clear opt-out, and owner notification. Voice can come later only if
the textback pilot proves value.
```

## Objection: Send Me Info

```text
I can send the one-page summary. Before I do, what would make this worth trying:
recovering one extra booked job per week, faster follow-up, or less after-hours
manual work?
```
